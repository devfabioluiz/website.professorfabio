Laços de Repetição em TypeScript

Tópicos do nosso plano de curso abordados nessa aula: Laços de repetição (for, while, do while, for...of, for...in), Palavras-chave break e continue, break com label, Integração com enums e condicionais.

Laços de Repetição

Laços de repetição permitem executar um bloco de código várias vezes de forma automática. Em vez de escrever a mesma linha 10 vezes, você cria um laço que faz isso por você.

Cada tipo de laço tem um uso ideal — saber escolher o certo torna seu código mais legível e eficiente.

for — o clássico

Ideal quando você sabe quantas vezes precisa repetir. Ele gerencia automaticamente uma variável contadora. 

// Exemplo real: calcular preço total de um carrinho de compras
const precos: number[] = [49.9, 29.9, 89.9, 15.9];
let total: number = 0;

for (let i = 0; i < precos.length; i++) {
  total += precos[i];
}

console.log(`Total do carrinho: R$ ${total.toFixed(2)}`);
// Total do carrinho: R$ 185.60

Explicando o código

O for funciona em três partes: let i = 0 (inicia o contador em 0), i < precos.length (roda enquanto for menor que 4, que é o tamanho do array), i++ (incrementa 1 a cada volta).

A cada iteração, somamos precos[i] ao total. No final, temos a soma de todos os preços.

while — repete enquanto a condição for verdadeira

Útil quando você não sabe quantas vezes vai repetir — a repetição depende de uma condição que pode mudar durante a execução. 

// Exemplo real: simular tentativas de login
let tentativas: number = 0;
const maxTentativas: number = 3;
const senhaCorreta: string = "minhaSena123";
let senhaDigitada: string = "errada";

while (tentativas < maxTentativas && senhaDigitada !== senhaCorreta) {
  tentativas++;
  console.log(`Tentativa ${tentativas}: senha incorreta`);

  // Simulando que na 2ª tentativa o usuário acerta
  if (tentativas === 2) {
    senhaDigitada = "minhaSena123";
  }
}

if (senhaDigitada === senhaCorreta) {
  console.log("Login realizado com sucesso!");
} else {
  console.log("Conta bloqueada. Tente novamente mais tarde.");
}
// Tentativa 1: senha incorreta
// Tentativa 2: senha incorreta
// Login realizado com sucesso!

Explicando o código

O while verifica a condição antes de cada repetição. Enquanto o número de tentativas for menor que 3 E a senha estiver errada, o laço continua.

Note que a condição tem duas partes ligadas por &&: se o usuário acertar a senha antes de esgotar as tentativas, o laço para. Se errar 3 vezes, também para.

do...while — executa pelo menos uma vez

Diferente do while, o do...while executa o bloco primeiro e depois verifica a condição. Útil quando a primeira execução é garantida. 

// Exemplo real: exibir menu de opções até o usuário escolher sair
let opcao: number;

do {
  console.log("===== MENU =====");
  console.log("1 - Ver saldo");
  console.log("2 - Fazer depósito");
  console.log("3 - Ver extrato");
  console.log("0 - Sair");

  // Simulando seleção do usuário (em app real seria input)
  opcao = Math.floor(Math.random() * 5); // gera 0 a 4

  switch (opcao) {
    case 1:
      console.log("Saldo: R$ 1.250,00");
      break;
    case 2:
      console.log("Depósito realizado!");
      break;
    case 3:
      console.log("Extrato: última transação R$ -50,00");
      break;
    case 0:
      console.log("Saindo do sistema...");
      break;
    default:
      console.log("Opção inválida. Tente novamente.");
  }
} while (opcao !== 0);

Explicando o código

O menu é exibido pelo menos uma vez antes de qualquer verificação. O do...while é perfeito para menus, formulários interativos e qualquer cenário onde a primeira execução é garantida.

O Math.floor(Math.random() * 5) gera um número aleatório entre 0 e 4. Em uma aplicação real, o valor viria de um input do usuário.

Laços Modernos: for...of e for...in

O TypeScript/JavaScript moderno oferece duas formas mais limpas de iterar: for...of para valores e for...in para índices/propriedades.

for...of — itera sobre valores

Percorre os valores de um array, string ou qualquer objeto iterável. É mais limpo que o for clássico porque não precisa de contador. 

// Exemplo: processar lista de pedidos
const pedidos: string[] = ["Notebook", "Mouse", "Teclado"];

// Com for clássico (mais verboso)
for (let i = 0; i < pedidos.length; i++) {
  console.log(`Pedido ${i + 1}: ${pedidos[i]}`);
}

// Com for...of (mais limpo)
for (const pedido of pedidos) {
  console.log(`Pedido: ${pedido}`);
}
// Pedido: Notebook
// Pedido: Mouse
// Pedido: Teclado

Explicando o código

O for...of direto nos dá o valor de cada elemento. Não precisamos de pedidos[i] — a variável pedido já contém o valor. Código mais limpo, menos propenso a erros.

Importante: for...of funciona com arrays, strings, maps e sets. NÃO funciona com objetos comuns (para isso, use for...in).

for...of com strings

// Exemplo: contar letras de uma palavra
const palavra: string = "TypeScript";
let vogais: number = 0;

for (const letra of palavra) {
  if ("aeiouAEIOU".includes(letra)) {
    vogais++;
  }
}

console.log(`"${palavra}" tem ${vogais} vogais`);
// "TypeScript" tem 3 vogais

Explicando o código

Strings são iteráveis — cada iteração nos dá uma letra. O método .includes() verifica se a letra está na string de vogais. Combinando for...of com condicionais, fazemos análises simples de texto.

for...in — itera sobre propriedades

Percorre os índices de um array ou propriedades de um objeto. Útil quando você precisa do nome da chave, não só do valor. 

// Exemplo: exibir dados de um usuário
const usuario: { nome: string; email: string; idade: number } = {
  nome: "Ana",
  email: "ana@email.com",
  idade: 28
};

for (const chave in usuario) {
  const valor = usuario[chave as keyof typeof usuario];
  console.log(`${chave}: ${valor}`);
}
// nome: Ana
// email: ana@email.com
// idade: 28

Explicando o código

O for...in percorre as chaves do objeto: "nome", "email", "idade". Para acessar o valor, usamos usuario[chave].

A expressão chave as keyof typeof usuario é uma type assertion — informa ao TypeScript que a chave é uma das propriedades válidas do objeto. Sem isso, o TypeScript não permitiria o acesso dinâmico.

Comparação: for...of vs for...in

Laço O que percorre Retorna Use para
for...of Valores de array/string O valor Processar dados, calcular totais
for...in Chaves de objeto O nome da propriedade Exibir campos, serializar dados

Palavras-chave: break e continue

Essas duas palavras-chave controlam o fluxo dentro de um laço: break para completamente o laço, enquanto continue pula para a próxima iteração.

break — parar o laço

Útil quando você encontrou o que procurava e não precisa continuar. 

// Exemplo real: buscar um produto pelo ID em uma lista
type Produto = {
  id: number;
  nome: string;
  preco: number;
};

const produtos: Produto[] = [
  { id: 1, nome: "Notebook", preco: 3500 },
  { id: 2, nome: "Mouse", preco: 89 },
  { id: 3, nome: "Teclado", preco: 199 },
  { id: 4, nome: "Monitor", preco: 1200 }
];

const idBuscado: number = 3;
let encontrado: Produto | null = null;

for (const produto of produtos) {
  if (produto.id === idBuscado) {
    encontrado = produto;
    break; // encontrou, para o loop
  }
}

if (encontrado) {
  console.log(`Produto: ${encontrado.nome} — R$ ${encontrado.preco}`);
} else {
  console.log("Produto não encontrado.");
}
// Produto: Teclado — R$ 199

Explicando o código

Ao encontrar o produto com id === 3, o break interrompe o laço imediatamente. Sem ele, o laço continuaria verificando os produtos restantes (Monitor) mesmo depois de encontrar o Teclado.

Em listas grandes, o break economiza processamento — para tudo quando encontra o que precisa.

continue — pular para a próxima iteração

Quando você quer pular um item específico mas continuar processando os outros. 

// Exemplo real: processar pedidos, pulando os cancelados
type Pedido = {
  id: number;
  cliente: string;
  status: "pendente" | "processando" | "cancelado";
};

const pedidos: Pedido[] = [
  { id: 1, cliente: "Ana", status: "pendente" },
  { id: 2, cliente: "Bob", status: "cancelado" },
  { id: 3, cliente: "Carlos", status: "processando" },
  { id: 4, cliente: "Diana", status: "cancelado" },
  { id: 5, cliente: "Eva", status: "pendente" }
];

let processados: number = 0;

for (const pedido of pedidos) {
  if (pedido.status === "cancelado") {
    console.log(`Pedido #${pedido.id} cancelado — pulando...`);
    continue; // pula para o próximo pedido
  }

  processados++;
  console.log(`Processando pedido #${pedido.id} (${pedido.cliente})`);
}

console.log(`Total processados: ${processados}`);
// Pedido #2 cancelado — pulando...
// Processando pedido #1 (Ana)
// Processando pedido #3 (Carlos)
// Pedido #4 cancelado — pulando...
// Processando pedido #5 (Eva)
// Total processados: 3

Explicando o código

O continue pula o restante do bloco e vai direto para a próxima iteração. Os pedidos cancelados são registrados no log mas não são processados — o processados++ só acontece para pedidos válidos.

Sem o continue, precisaríamos de um if maior envolvendo todo o código de processamento, tornando o código mais indentado e difícil de ler.

break com label — sair de loop aninhado

Quando loops estão aninhados, o break só sai do laço mais interno. Com um label, você pode sair de qualquer nível. 

// Exemplo real: buscar produto em múltiplas lojas
const lojas: string[][] = [
  ["Notebook", "Mouse"],        // Loja Centro
  ["Teclado", "Monitor"],       // Loja Zona Sul
  ["Webcam", "Headset"],        // Loja Leste
];

const itemBuscado: string = "Monitor";
let encontrado: boolean = false;

// Label "lojaLoop" no laço externo
lojaLoop: for (let i = 0; i < lojas.length; i++) {
  for (let j = 0; j < lojas[i].length; j++) {
    if (lojas[i][j] === itemBuscado) {
      console.log(`Encontrado na Loja ${i + 1}, posição ${j + 1}`);
      encontrado = true;
      break lojaLoop; // sai de AMBOS os loops
    }
  }
}

if (!encontrado) {
  console.log("Produto não encontrado em nenhuma loja.");
}
// Encontrado na Loja 2, posição 2

Explicando o código

O label lojaLoop: é colocado antes do laço externo. Quando usamos break lojaLoop, saímos de todos os loops aninhados — tanto o interno (produtos da loja) quanto o externo (lojas).

Sem o label, o break sairia apenas do loop interno e começaria a verificar a próxima loja. O label é essencial para buscas em estruturas aninhadas.

Comparação: break vs continue

Palavra-chave O que faz Exemplo de uso
break Para o laço completamente Encontrou o item que buscava
continue Pula para a próxima iteração Quer ignorar itens inválidos
break label Sai de loop aninhado Busca em estrutura 2D

Integrando Laços com Enums e Condicionais

Na aula anterior, aprendemos enums e condicionais. Agora vamos combiná-los com laços — algo que acontece constantemente em projetos reais.

Exemplo: processar diferentes status de pedido

enum StatusPedido {
  Pendente = "PENDENTE",
  Processando = "PROCESSANDO",
  Enviado = "ENVIADO",
  Entregue = "ENTREGUE",
  Cancelado = "CANCELADO"
}

const listaPedidos: StatusPedido[] = [
  StatusPedido.Pendente,
  StatusPedido.Processando,
  StatusPedido.Enviado,
  StatusPedido.Pendente,
  StatusPedido.Entregue
];

let pendentes: number = 0;
let emTransito: number = 0;

for (const status of listaPedidos) {
  switch (status) {
    case StatusPedido.Pendente:
      pendentes++;
      break;
    case StatusPedido.Enviado:
    case StatusPedido.Processando:
      emTransito++;
      break;
    case StatusPedido.Entregue:
      console.log("Pedido entregue com sucesso!");
      break;
    case StatusPedido.Cancelado:
      console.log("Pedido cancelado — ignorando...");
      break;
  }
}

console.log(`Pendentes: ${pendentes}`);
console.log(`Em trânsito: ${emTransito}`);
// Pendentes: 2
// Em trânsito: 2

Explicando o código

Note o case StatusPedido.Enviado: seguido de case StatusPedido.Processando: sem break entre eles — isso é fall-through intencional. Ambos os status são tratados da mesma forma (incrementar emTransito).

Esse padrão é muito usado quando múltiplos valores devem ter o mesmo tratamento. É como um "ou" no switch.

Exemplo: gerar relatório com while e enum

enum NivelLog {
  Info = "INFO",
  Warning = "WARNING",
  Error = "ERROR"
}

type LogEntry = {
  nivel: NivelLog;
  mensagem: string;
};

const logs: LogEntry[] = [
  { nivel: NivelLog.Info, mensagem: "Servidor iniciado" },
  { nivel: NivelLog.Warning, mensagem: "Uso de memória alto" },
  { nivel: NivelLog.Error, mensagem: "Falha na conexão com banco" },
  { nivel: NivelLog.Info, mensagem: "Reconectando..." },
  { nivel: NivelLog.Error, mensagem: "Timeout na requisição" }
];

let index: number = 0;
let erros: number = 0;

while (index < logs.length) {
  const log = logs[index];

  if (log.nivel === NivelLog.Error) {
    erros++;
    console.log(`[ERRO] ${log.mensagem}`);
  }

  index++;
}

console.log(`\nTotal de erros encontrados: ${erros}`);
// [ERRO] Falha na conexão com banco
// [ERRO] Timeout na requisição
// Total de erros encontrados: 2

Explicando o código

O while percorre o array de logs com um contador manual. A cada iteração, verifica se o nível é Error e conta quantos erros ocorreram. Em um sistema real, esse tipo de lógica é usado para dashboards de monitoramento e alertas.

Quando usar cada tipo de laço

Laço Use quando... Não use quando...
for Sabe o número de iterações, precisa do índice Só precisa dos valores (use for...of)
for...of Iterar valores de array/string sem precisar do índice Precisa do índice ou das propriedades de um objeto
for...in Percorrer propriedades de um objeto Iterar arrays (use for ou for...of)
while Conição baseada em estado, número de iterações desconhecido Precisa executar pelo menos uma vez (use do...while)
do...while Precisa executar pelo menos uma vez (menus, formulários) A primeira execução pode ser desnecessária

Crie um arquivo src/pedidos-lacos.ts que combine laços, enums e condicionais para processar pedidos de uma loja online:

  { id: 4, cliente: "Diana", status: StatusPedido.Enviado },
  { id: 5, cliente: "Eva", status: StatusPedido.Cancelado },
  { id: 6, cliente: "Frank", status: StatusPedido.Entregue },
  { id: 7, cliente: "Gabriela", status: StatusPedido.Novo },
  { id: 8, cliente: "Hugo", status: StatusPedido.Enviado }
];

let novos: number = 0;
let emPreparo: number = 0;
let enviados: number = 0;
let entregues: number = 0;
let cancelados: number = 0;
let parouEmPreparo: boolean = false;

for (const pedido of pedidos) {
  // Pular cancelados
  if (pedido.status === StatusPedido.Cancelado) {
    cancelados++;
    console.log(`Pedido #${pedido.id} cancelado — pulando...`);
    continue;
  }

  // Parar ao encontrar "EmPreparo"
  if (pedido.status === StatusPedido.EmPreparo && !parouEmPreparo) {
    console.log(`\nPedido #${pedido.id} em preparo — parando busca.`);
    parouEmPreparo = true;
    // Não dá break aqui para continuar contando os outros status
  }

  switch (pedido.status) {
    case StatusPedido.Novo:
      novos++;
      break;
    case StatusPedido.EmPreparo:
      emPreparo++;
      break;
    case StatusPedido.Enviado:
      enviados++;
      break;
    case StatusPedido.Entregue:
      entregues++;
      break;
  }
}

// Relatório final
console.log("\n===== RELATÓRIO =====");
console.log(`Novos: ${novos}`);
console.log(`Em preparo: ${emPreparo}`);
console.log(`Enviados: ${enviados}`);
console.log(`Entregues: ${entregues}`);
console.log(`Cancelados: ${cancelados}`);

Explicando o código

O exercício combina todos os conceitos da aula: enums para definir status, for...of para iterar, continue para pular cancelados, switch para contar cada status, e uma flag parouEmPreparo para rastrear quando encontramos o primeiro pedido em preparo.

Note que o continue é executado antes do switch — pedidos cancelados nem chegam ao switch. Isso mantém o código limpo e evita processamento desnecessário.

A flag parouEmPreparo é um padrão comum quando você quer executar algo apenas na primeira ocorrência mas continuar o loop para processar os demais.
