Arrays em TypeScript

Um array é uma coleção ordenada de elementos. No TypeScript, arrays são fortemente tipados — você define qual tipo de dado o array pode armazenar, e o compilador garante que apenas valores válidos entrem nele.

Sintaxe básica

// Sintaxe com colchetes (mais comum)
const numeros: number[] = [10, 20, 30, 40];
const nomes: string[] = ["Ana", "João", "Maria"];
const ativo: boolean[] = [true, false, true];

// Sintaxe com Array<> (alternativa)
const notas: Array<number> = [7.5, 8.0, 9.2];

// Array vazio com tipo explícito
const itens: string[] = [];

Explicando o código

A sintaxe number[] é equivalente a Array<number> — ambas criam um array que só aceita números. A primeira é mais usada por ser mais curta e legível.

Se tentar fazer numeros.push("texto"), o TypeScript gera um erro de compilação. Isso evita bugs silenciosos em tempo de execução.

Arrays de objetos

type Produto = {
  id: number;
  nome: string;
  preco: number;
};

const carrinho: Produto[] = [
  { id: 1, nome: "Notebook", preco: 3500 },
  { id: 2, nome: "Mouse", preco: 89 },
  { id: 3, nome: "Teclado", preco: 199 }
];

Explicando o código

Ao definir Produto[], cada elemento do array deve seguir a estrutura do tipo Produto: ter id (number), nome (string) e preco (number). Se faltar uma propriedade ou o tipo estiver errado, o TypeScript avisa.

Tuples

Uma tuple (tupla) é um array com um número fixo de elementos, onde cada posição tem um tipo específico. É como um "mini-objeto" muito leve. 

// Tuple: [string, number] — primeiro é string, segundo é number
const pessoa: [string, number] = ["Ana", 28];

console.log(pessoa[0]); // "Ana" (string)
console.log(pessoa[1]); // 28 (number)

// pessoa[0] = 100; // ERRO: não pode atribuir number a string

// Named tuples (mais legível — apenas anotação)
type Coordenada = [number, number];

const posicao: Coordenada = [10, 25];

// Tuple com readonly (imutável)
const registro: readonly [string, boolean] = ["ativo", true];

Explicando o código

Diferente de um array normal (number[] — qualquer quantidade de números), uma tuple tem tamanho fixo e tipos específicos por posição. [string, number] sempre terá exatamente 2 elementos: o primeiro string, o segundo number.

O readonly torna a tuple imutável — nem os valores podem ser alterados após a criação.

Quando usar tuple vs objeto

Tuple Objeto
Posições fixas com tipos diferentes Propriedades nomeadas
Leve, sem overhead de chaves Mais legível quando há muitas propriedades
Útil para retorno de funções com poucos valores Útil para dados complexos

Métodos essenciais de Array

Os métodos de array são funções que manipulam coleções de dados. No TypeScript, eles são totalmente tipados — o retorno de cada método é inferido automaticamente.

forEach — iterar sem retorno

const frutas: string[] = ["Maçã", "Banana", "Laranja"];

frutas.forEach((fruta, index) => {
  console.log(`${index + 1}. ${fruta}`);
});
// 1. Maçã
// 2. Banana
// 3. Laranja

map — transformar cada elemento

const precos: number[] = [10, 20, 30];

// Cria um NOVO array com cada preço com 10% de desconto
const precosComDesconto = precos.map(preco => preco * 0.9);

console.log(precosComDesconto); // [9, 18, 27]
console.log(precos);            // [10, 20, 30] (original não muda)

Explicando o código

O map retorna um novo array — o original não é modificado. Cada elemento passa pela função e o resultado substitui o item na mesma posição. É um dos métodos mais usados no desenvolvimento front-end (React, Angular) para renderizar listas.

filter — manter apenas elementos que passam no teste

type Produto = {
  id: number;
  nome: string;
  preco: number;
  emEstoque: boolean;
};

const produtos: Produto[] = [
  { id: 1, nome: "Notebook", preco: 3500, emEstoque: true },
  { id: 2, nome: "Mouse", preco: 89, emEstoque: false },
  { id: 3, nome: "Teclado", preco: 199, emEstoque: true },
  { id: 4, nome: "Monitor", preco: 1200, emEstoque: true }
];

// Filtrar apenas produtos em estoque
const disponiveis = produtos.filter(p => p.emEstoque);
console.log(disponiveis.length); // 3

// Filtrar por preço
const baratos = produtos.filter(p => p.preco < 200);
console.log(baratos.map(p => p.nome)); // ["Mouse", "Teclado"]

Explicando o código

O filter recebe uma função que retorna true ou false. Apenas os elementos cuja função retornar true ficam no novo array. O tipo do retorno é inferido automaticamente — disponiveis tem tipo Produto[].

find — buscar o primeiro elemento

const usuarios: { id: number; nome: string }[] = [
  { id: 1, nome: "Ana" },
  { id: 2, nome: "Bob" },
  { id: 3, nome: "Carlos" }
];

// Retorna o primeiro que satisfaz a condição (ou undefined)
const bob = usuarios.find(u => u.nome === "Bob");
console.log(bob); // { id: 2, nome: "Bob" }

const inexistente = usuarios.find(u => u.nome === "Diana");
console.log(inexistente); // undefined

reduce — agregar em um único valor

const numeros: number[] = [10, 20, 30, 40];

// Somar todos os valores
const total = numeros.reduce((acumulador, atual) => acumulador + atual, 0);
console.log(total); // 100

// Agrupar produtos por categoria
type Produto = {
  nome: string;
  categoria: string;
  preco: number;
};

const produtos: Produto[] = [
  { nome: "Notebook", categoria: "TI", preco: 3500 },
  { nome: "Mouse", categoria: "TI", preco: 89 },
  { nome: "Cadeira", categoria: "Móvel", preco: 450 }
];

const porCategoria = produtos.reduce((acc, produto) => {
  if (!acc[produto.categoria]) {
    acc[produto.categoria] = [];
  }
  acc[produto.categoria].push(produto);
  return acc;
}, {} as Record<string, Produto[]>);

console.log(porCategoria);
// { TI: [Notebook, Mouse], Móvel: [Cadeira] }

Explicando o código

O reduce percorre o array e vai acumulando resultados em uma variável (o primeiro parâmetro, acumulador). O segundo parâmetro (0 ou {}) é o valor inicial.

No primeiro exemplo, somamos números. No segundo, agrupamos objetos por categoria — um padrão muito usado para transformar listas em dados estruturados.

some e every — verificar condições

const idades: number[] = [22, 17, 25, 30, 15];

// some: pelo menos UM elemento satisfaz?
const temMenor = idades.some(idade => idade < 18);
console.log(temMenor); // true (17 e 15)

// every: TODOS satisfazem?
const todosMaiores = idades.every(idade => idade >= 18);
console.log(todosMaiores); // false (17 e 15 existem)

sort — ordenar

// Strings — ordenação alfabética
const nomes: string[] = ["Carlos", "Ana", "Bruno"];
nomes.sort();
console.log(nomes); // ["Ana", "Bruno", "Carlos"]

// Números — precisa de comparador!
const notas: number[] = [7.5, 9.0, 6.2, 8.8];
notas.sort((a, b) => a - b); // crescente
console.log(notas); // [6.2, 7.5, 8.8, 9.0]

notas.sort((a, b) => b - a); // decrescente
console.log(notas); // [9.0, 8.8, 7.5, 6.2]

Explicando o código

Cuidado: o sort() sem comparador ordena como strings — [10, 9, 80] ficaria [10, 80, 9]. Para números, sempre passe uma função comparadora: (a, b) => a - b para crescente.

Outro ponto: o sort() modifica o array original. Para ordenar sem alterar, faça uma cópia primeiro: [...notas].sort((a, b) => a - b).

Outros métodos úteis

const cores: string[] = ["vermelho", "azul", "verde"];

// includes — verificar se existe
console.log(cores.includes("azul")); // true

// indexOf — posição de um elemento
console.log(cores.indexOf("verde")); // 2

// slice — extrair parte
const doisPrimeiros = cores.slice(0, 2);
console.log(doisPrimeiros); // ["vermelho", "azul"]

// splice — remover/inserir (modifica o original)
const copia = [...copia];
copia.splice(1, 1); // remove 1 item a partir da posição 1
console.log(copia); // ["vermelho", "verde"]

// flat — aplanar array aninhado
const aninhado: number[][] = [[1, 2], [3, 4], [5]];
console.log(aninhado.flat()); // [1, 2, 3, 4, 5]

// concat — juntar arrays
const a = [1, 2];
const b = [3, 4];
console.log(a.concat(b)); // [1, 2, 3, 4]

Exemplo Integrador: Sistema de Carrinho

Vamos combinar os métodos de array em um cenário real — um sistema de carrinho de compras com filtros, totais e ordenação. 

type Produto = {
  id: number;
  nome: string;
  preco: number;
  categoria: string;
  emEstoque: boolean;
};

const produtos: Produto[] = [
  { id: 1, nome: "Notebook", preco: 3500, categoria: "TI", emEstoque: true },
  { id: 2, nome: "Mouse", preco: 89, categoria: "TI", emEstoque: true },
  { id: 3, nome: "Cadeira", preco: 450, categoria: "Móvel", emEstoque: false },
  { id: 4, nome: "Teclado", preco: 199, categoria: "TI", emEstoque: true },
  { id: 5, nome: "Monitor", preco: 1200, categoria: "TI", emEstoque: true },
  { id: 6, nome: "Mesa", preco: 800, categoria: "Móvel", emEstoque: true }
];

// 1. Filtrar apenas produtos em estoque
const disponiveis = produtos.filter(p => p.emEstoque);

// 2. Produtos de TI com preço inferior a R$ 500
const tiBaratos = produtos.filter(p => p.categoria === "TI" && p.preco < 500);
console.log("TI baratos:", tiBaratos.map(p => p.nome));
// ["Mouse", "Teclado"]

// 3. Total do carrinho (todos os disponíveis)
const total = disponiveis.reduce((soma, p) => soma + p.preco, 0);
console.log(`Total: R$ ${total}`);
// Total: R$ 5188

// 4. Ordenar por preço crescente
const porPreco = [...disponiveis].sort((a, b) => a.preco - b.preco);
console.log("Mais baratos:", porPreco.map(p => `${p.nome}: R$ ${p.preco}`));
// Mouse: R$ 89, Teclado: R$ 199, ...

// 5. Existe produto acima de R$ 3000?
const temCaro = disponiveis.some(p => p.preco > 3000);
console.log("Tem produto caro?", temCaro); // true

// 6. Todos estão em estoque?
const todosDisponiveis = disponiveis.every(p => p.emEstoque);
console.log("Todos disponíveis?", todosDisponiveis); // true

// 7. Buscar produto por ID
const produto = produtos.find(p => p.id === 3);
console.log("Produto 3:", produto?.nome); // "Cadeira"

Explicando o código

Este exemplo mostra como os métodos de array se complementam: filter seleciona, map transforma, reduce agrega, sort ordena, some/every verificam, e find busca.

Note o uso de [...disponiveis] para copiar o array antes de ordenar — assim não modificamos o array filtrado original.

Generics (Tipos Genéricos)

Generics permitem criar funções, interfaces e classes que funcionam com qualquer tipo, mas sem perder a segurança de tipos. É como um "placeholder de tipo" que só será definido quando o código for usado.

Por que Generics?

// SEM generics — precisamos usar any (perde segurança)
function pegarPrimeiroAny(arr: any[]): any {
  return arr[0];
}

const nome = pegarPrimeiroAny(["Ana", "João"]); // any — sem tipo!
const numero = pegarPrimeiroAny([10, 20, 30]);  // any — sem tipo!

// COM generics — tipo é inferido e mantido
function pegarPrimeiro<T>(arr: T[]): T {
  return arr[0];
}

const nome2 = pegarPrimeiro(["Ana", "João"]);  // tipo: string
const numero2 = pegarPrimeiro([10, 20, 30]);    // tipo: number

// O TypeScript SABE que nome2 é string:
console.log(nome2.toUpperCase()); // OK
// console.log(numero2.toUpperCase()); // ERRO: number não tem toUpperCase

Explicando o código

Sem generics, usamos any — o TypeScript perde toda a verificação de tipo. Com generics, o T é substituído pelo tipo real quando a função é chamada. Se passarmos ["Ana", "João"], o T vira string.

A grande vantagem: o TypeScript infere o tipo automaticamente. Não precisamos escrever pegarPrimeiro<string>([...]) — ele descobre sozinho.

Restrições em Generics

Às vezes precisamos garantir que o tipo genérico tenha certas propriedades. Usamos extends para definir essas restrições. 

// Restrição: T deve ter uma propriedade "length"
function logComprimento<T extends { length: number }>(item: T): void {
  console.log(`Comprimento: ${item.length}`);
}

logComprimento("Hello");           // OK: string tem length
logComprimento([1, 2, 3]);         // OK: array tem length
// logComprimento(123);            // ERRO: number não tem length

// Restrição: T deve ser um objeto com "id"
type ComId = { id: number };

function buscarPorId<T extends ComId>(lista: T[], id: number): T | undefined {
  return lista.find(item => item.id === id);
}

type Usuario = { id: number; nome: string };
type Produto = { id: number; nome: string; preco: number };

const usuarios: Usuario[] = [{ id: 1, nome: "Ana" }];
const produtos: Produto[] = [{ id: 1, nome: "Notebook", preco: 3500 }];

buscarPorId(usuarios, 1);  // OK: Usuario tem id
buscarPorId(produtos, 1);  // OK: Produto tem id

Explicando o código

T extends { length: number } significa: "T pode ser qualquer tipo, desde que tenha uma propriedade length do tipo number". Strings, arrays e typed arrays atendem a essa restrição; números e booleans não.

Isso é extremamente útil para criar funções genéricas que funcionam com múltiplos tipos mas ainda assim garantem que certas propriedades existam.

Interfaces e Classes Genéricas

Interface genérica

// Interface que funciona com qualquer tipo de dado
interface RespostaAPI<T> {
  dados: T;
  status: number;
  mensagem: string;
  timestamp: Date;
}

// Usando com diferentes tipos
const respostaUsuarios: RespostaAPI<Usuario[]> = {
  dados: [{ id: 1, nome: "Ana" }],
  status: 200,
  mensagem: "Sucesso",
  timestamp: new Date()
};

type Usuario = { id: number; nome: string };

const respostaErro: RespostaAPI<null> = {
  dados: null,
  status: 500,
  mensagem: "Erro interno",
  timestamp: new Date()
};

Explicando o código

A interface RespostaAPI<T> define a estrutura de uma resposta de API. O tipo T é o tipo dos dados retornados — pode ser Usuario[], null, ou qualquer outro tipo. Isso reutiliza a mesma estrutura para diferentes endpoints.

Classe genérica

// Repositório genérico — funciona com qualquer tipo de dados
class Repository<T> {
  private items: T[] = [];

  adicionar(item: T): void {
    this.items.push(item);
  }

  buscarPorIndice(index: number): T | undefined {
    return this.items[index];
  }

  listar(): T[] {
    return [...this.items];
  }

  filtrar(predicate: (item: T) => boolean): T[] {
    return this.items.filter(predicate);
  }
}

// Usando com Produto
type Produto = { id: number; nome: string; preco: number };

const produtoRepo = new Repository<Produto>();
produtoRepo.adicionar({ id: 1, nome: "Notebook", preco: 3500 });
produtoRepo.adicionar({ id: 2, nome: "Mouse", preco: 89 });

const baratos = produtoRepo.filtrar(p => p.preco < 200);
console.log(baratos.map(p => p.nome)); // ["Mouse"]

// Usando com Usuário
type Usuario = { id: number; nome: string };

const usuarioRepo = new Repository<Usuario>();
usuarioRepo.adicionar({ id: 1, nome: "Ana" });
usuarioRepo.adicionar({ id: 2, nome: "Bob" });

const todos = usuarioRepo.listar();
console.log(todos.length); // 2

Explicando o código

A classe Repository<T> é um padrão muito usado em aplicações reais — ela gerencia uma coleção de dados de qualquer tipo. Criamos uma instância para Produto e outra para Usuario, e cada uma só aceita o tipo correspondente.

Isso elimina a necessidade de criar classes separadas (ProdutoRepository, UsuarioRepository) com código duplicado.

Interface genérica com constraint

// Interface que exige que T tenha "id"
interface EntidadeComId {
  id: number;
}

interface Cache<T extends EntidadeComId> {
  dados: Map<number, T>;
  obter(id: number): T | undefined;
  salvar(item: T): void;
  remover(id: number): void;
}

// Implementação concreta
class CacheLocal<T extends EntidadeComId> implements Cache<T> {
  dados = new Map<number, T>();

  obter(id: number): T | undefined {
    return this.dados.get(id);
  }

  salvar(item: T): void {
    this.dados.set(item.id, item);
  }

  remover(id: number): void {
    this.dados.delete(id);
  }
}

type Produto = { id: number; nome: string; preco: number };

const cache = new CacheLocal<Produto>();
cache.salvar({ id: 1, nome: "Notebook", preco: 3500 });
console.log(cache.obter(1)?.nome); // "Notebook"

};

type Usuario = {
  id: number;
  nome: string;
  email: string;
};

// Classe genérica
class Catalogo<T> {
  private items: T[] = [];

  adicionar(item: T): void {
    this.items.push(item);
  }

  listar(): T[] {
    return [...this.items];
  }

  filtrar(predicate: (item: T) => boolean): T[] {
    return this.items.filter(predicate);
  }

  buscarPorIndice(index: number): T | undefined {
    return this.items[index];
  }
}

// Catálogo de produtos
const produtos = new Catalogo<Produto>();
produtos.adicionar({ id: 1, nome: "Notebook", preco: 3500, categoria: "TI", emEstoque: true });
produtos.adicionar({ id: 2, nome: "Mouse", preco: 89, categoria: "TI", emEstoque: true });
produtos.adicionar({ id: 3, nome: "Cadeira", preco: 450, categoria: "Móvel", emEstoque: false });
produtos.adicionar({ id: 4, nome: "Teclado", preco: 199, categoria: "TI", emEstoque: true });
produtos.adicionar({ id: 5, nome: "Mesa", preco: 800, categoria: "Móvel", emEstoque: true });
produtos.adicionar({ id: 6, nome: "Monitor", preco: 1200, categoria: "TI", emEstoque: true });

// Filtrar por categoria
const ti = produtos.filtrar(p => p.categoria === "TI");
console.log("Produtos TI:", ti.map(p => p.nome));

// Ordenar por preço
const porPreco = [...produtos.listar()].sort((a, b) => a.preco - b.preco);
console.log("Por preço:", porPreco.map(p => `${p.nome}: R$ ${p.preco}`));

// Total dos disponíveis
const total = produtos.filtrar(p => p.emEstoque).reduce((soma, p) => soma + p.preco, 0);
console.log(`Total: R$ ${total}`);

// Catálogo de usuários
const usuarios = new Catalogo<Usuario>();
usuarios.adicionar({ id: 1, nome: "Ana", email: "ana@email.com" });
usuarios.adicionar({ id: 2, nome: "Bob", email: "bob@email.com" });

console.log("Usuários:", usuarios.listar().map(u => u.nome));

Explicando o código

A classe Catalogo<T> funciona para qualquer tipo de dados — produtos, usuários, ou qualquer coisa que tenha uma estrutura definida. Isso elimina código duplicado e mantém a segurança de tipos.

Cada catálogo (produtos e usuários) é uma instância separada da mesma classe genérica. O TypeScript garante que o catálogo de produtos só aceite Produto e o de usuários só aceite Usuario.
