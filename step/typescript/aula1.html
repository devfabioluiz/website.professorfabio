O que é TypeScript?

TypeScript é um superset (superconjunto) do JavaScript. Ele adiciona tipagem estática, interfaces, modificadores de acesso, enumerações e outros recursos de linguagens mais robustas como Java ou C#.

TypeScript adiciona tipagem estática ao JavaScript, o que significa que você pode definir os tipos de variáveis, parâmetros de funções e retornos. Isso facilita a detecção de erros antes mesmo de executar o código. Benefícios do TypeScript:

  • Detecção precoce de erros: Menos bugs em produção.
  • Compatível com JavaScript: Permite a migração gradual de projetos.

História do TypeScript

  • Criado pela Microsoft em 2012.
  • Idealizado por Anders Hejlsberg, criador do C#.
  • Surgiu da necessidade de organizar grandes projetos JS.
  • Hoje amplamente usado com frameworks como Angular, React e Vue.

Objetivos e propósitos do TypeScript

  • Adicionar tipagem estática opcional.
  • Detectar erros antes da execução.
  • Facilitar desenvolvimento escalável.
  • Melhorar autocompletar e verificação nas IDEs.
  • Suporte a POO moderna.

Principais problemas do JavaScript (corrigidos pelo TypeScript)

Ausência de Tipagem Estática

let idade = 25;
idade = "vinte e cinco"; // Nenhum erro!

Problema: O tipo da variável pode mudar a qualquer momento, o que pode causar erros ocultos.

TypeScript corrige:

let idade: number = 25;
idade = "vinte e cinco";

Erro ao acessar propriedades inexistentes

const user = { nome: "Ana" };
console.log(user.idade); // undefined (mas sem erro!)

Problema: JS permite acessar propriedades que não existem, o que pode gerar falhas silenciosas.

TypeScript corrige:

const user: { nome: string } = { nome: "Ana" };
console.log(user.idade);

Problemas com NaN (Not a Number)

Exemplo em JavaScript:

function dividir(a, b) {
  return a / b;
}

console.log(dividir("abc", 2)); // NaN

Problema: O JavaScript não lança erro ao tentar dividir uma string por um número — retorna NaN. Esse erro só aparece em tempo de execução.

TypeScript corrige com verificação de tipos:

function dividir(a: number, b: number): number {
  return a / b;
}

dividir("abc", 2);

Com TypeScript, você previne o erro antes de executar o código, garantindo que os tipos estejam corretos.

Falta de recursos modernos (antes do ES6)

Antes do ES6, JavaScript não tinha classes, herança ou interfaces nativas. O TypeScript ofereceu essas ferramentas muito antes do JavaScript moderno.

Instalação do TypeScript

  1. Node.js: Certifique-se de que o Node.js está instalado na sua máquina.
    • Para verificar: node -v
  2. npm: Instalado automaticamente com o Node.js.
    • Para verificar: npm -v
  3. Abra o terminal e execute o comando: npm install -g typescript
    • Para verificar se o TypeScript foi instalado corretamente: tsc -v

Configurando um Projeto com TypeScript

  1. Crie uma pasta para o projeto: 
    mkdir meu-projeto-typescript
  2. cd meu-projeto-typescript
  3. Inicialize o projeto com npm: 
    npm init -y
  4. Adicione o TypeScript como dependência do projeto: 
    npm install typescript --save-dev
  5. Crie o arquivo de configuração do TypeScript: 
    tsc --init

Isso criará um arquivo tsconfig.json, onde você pode ajustar configurações como o diretório de saída (outDir) e o diretório de entrada (rootDir). 

// Exemplo básico de `tsconfig.json`:
{
  "compilerOptions": {
    "target": "ES6",
    "module": "commonjs",
    "strict": true,
    "outDir": "./dist",
    "rootDir": "./src"
  }
}

Agora instale o TypeScript globalmente:

npm install -g typescript

Verificar versão:

tsc -v

Passo 1 — Criar projeto TypeScript

Inicialize o projeto com npm e instale o TypeScript como dependência de desenvolvimento:


npm init -y
npm install typescript --save-dev
npx tsc --init

Agora crie a pasta src e configure o tsconfig.json da seguinte forma:


// tsconfig.json
{
  "compilerOptions": {
    "target": "ES6",
    "module": "commonjs",
    "strict": true,
    "outDir": "./dist",
    "rootDir": "./src"
  },
  "include": ["src/**/*.ts"],
  "exclude": ["dist"]
}

Explicando o codigo

target: "ES6" — Define a versão do JavaScript de saída. ES6 é amplamente suportada e permite usar let, const, arrow functions e template literals.

module: "commonjs" — Define o sistema de módulos. CommonJS é o padrão do Node.js.

strict: true — Ativa todas as verificações de tipo estritas, o que ajuda a encontrar erros antes de rodar o código.

outDir: "./dist" — Pasta onde os arquivos compilados (.js) serão salvos.

rootDir: "./src" — Pasta onde ficam os arquivos-fonte TypeScript (.ts).

Passo 2 — Criar o arquivo src/index.ts

Crie o arquivo index.ts dentro da pasta src e insira o código abaixo:


type Pessoa = {
  nome: string;
  saldo: number;
};

const exemplo: Pessoa = {
  nome: "Fabio",
  saldo: 3000,
};

function deposito(saldoCliente: number, valorDeposito: number): number {
  return saldoCliente + valorDeposito;
}

console.log(deposito(exemplo.saldo, 152));

Explicando o codigo

type Pessoa — Cria um alias de tipo (type alias). É como definir uma estrutura de dados: toda variável do tipo Pessoa deve ter as propriedades nome (string) e saldo (number).

const exemplo: Pessoa — Declara uma constante e a tipa como Pessoa. Se tentarmos adicionar uma propriedade que não existe no tipo, o TypeScript gera um erro.

function deposito(...): number — Os parâmetros saldoCliente e valorDeposito são tipados como number, e o retorno da função também é declarado como number. Se tentarmos passar uma string, o TypeScript avisa o erro antes de rodar o código.

Passo 3 — Compilar e rodar o projeto

Adicione o script de execução no package.json. Abra o arquivo e altere a seção "scripts" para:


"scripts": {
  "start": "npx tsc && node dist/index.js"
}

Agora execute o projeto com:


npm start

O TypeScript compilará os arquivos .ts da pasta src para .js na pasta dist, e o Node.js executará o arquivo resultante. Você verá no terminal: 


3152

Esse é o resultado de deposito(3000, 152), ou seja, o saldo de 3000 + depósito de 152 = 3152.

Último Passo — Subindo para o Git

Agora vamos subir as alterações para o repositório do Git. Execute os comandos abaixo:


git add .
git commit -m "aula 1 typescript introducao"

Entendendo os comandos Git

git add . — Adiciona todos os arquivos modificados (o . representa o diretório atual) à área de staging (preparação). É como "marcar" quais arquivos farão parte do próximo commit.

git commit -m "mensagem" — Cria um commit (um ponto na história do repositório) com os arquivos que estão em staging. A flag -m permite escrever a mensagem descritiva diretamente no comando.

git push — Envia os commits locais para o repositório remoto no GitHub. Como a branch aula1-typescript foi criada localmente com checkout -b, o Git pode pedir para usar --set-upstream na primeira vez (em aulas seguintes veremos isso).

Criar uma funcao saque e um tipo Conta

Crie um tipo chamado Conta com as propriedades titular (string) e saldo (number).

Em seguida, crie uma funcao chamada saque que receba o saldo atual e o valor do saque, e retorne o saldo subtraido.

Use o tipo Conta para criar um objeto e chame a funcao saque passando o saldo do objeto e um valor de sua escolha. Exiba o resultado no console.

Obs: Nao se esqueca de subir as alteracoes para o Git na branch dessa aula apos terminar o dever.

Gabarito:

Arquivo src/index.ts:


type Conta = {
  titular: string;
  saldo: number;
};

const minhaConta: Conta = {
  titular: "Fabio",
  saldo: 3000,
};

function saque(saldoAtual: number, valorSaque: number): number {
  return saldoAtual - valorSaque;
}

const saldoFinal = saque(minhaConta.saldo, 500);

console.log(`Saldo de ${minhaConta.titular}: ${saldoFinal}`);

Explicando o codigo

O tipo Conta funciona igual ao tipo Pessoa da aula: define a estrutura que o objeto deve seguir. A funcao saque segue o mesmo padrao da funcao deposito, porem subtraindo em vez de somar.

A variavel saldoFinal recebe o resultado da funcao e usamos um template literal (${ }) para exibir o nome do titular junto com o saldo no console.
