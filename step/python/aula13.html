Reconhecimento Facial com Python e OpenCV

Tópicos do nosso plano de curso abordados nessa aula: OpenCV, Haar Cascades, Detecção facial, Reconhecimento facial com LBPH, Captura por webcam.

Objetivo da aula

Nesta aula, vamos entrar no mundo da visão computacional com o OpenCV. Você vai aprender a processar imagens, detectar rostos em fotos e na webcam, e construir um sistema que reconhece pessoas pelo rosto usando o algoritmo LBPH.

Projeto: Vamos construir um Sistema de Reconhecimento Facial executável pelo terminal. Ele coleta amostras do seu rosto pela webcam, treina um modelo e passa a identificar quem está diante da câmera em tempo real.

Conteúdos da aula

  • O que é OpenCV e instalação dos pacotes
  • Ler e exibir imagens com cv2.imread e cv2.imshow
  • Detecção facial com Haar Cascades
  • Captura de frames ao vivo com cv2.VideoCapture
  • Reconhecimento facial com LBPH (Local Binary Patterns Histograms)
  • Coleta de amostras, treino do modelo e reconhecimento em tempo real

O que é OpenCV?

OpenCV (Open Source Computer Vision Library) é uma biblioteca open-source de visão computacional e aprendizado de máquina. Com ela, podemos processar imagens e vídeos em tempo real, detectar objetos, rostos, e até reconhecer pessoas.

  • Criada pela Intel em 1999
  • Suporte para Python, C++, Java e mais
  • Usada em robótica, segurança, automotiva, etc.
  • Mais de 2500 algoritmos otimizados

Como funciona a detecção facial

O OpenCV vem com classificadores pré-treinados chamados Haar Cascades. Eles usam características visuais (bordas, linhas, texturas) para detectar objetos. Para localizar um rosto em uma imagem, seguimos o fluxo:

  1. Carregar a imagem e converter para tons de cinza
  2. Aplicar o classificador detectMultiScale
  3. Desenhar um retângulo ao redor de cada rosto encontrado

A detecção apenas localiza rostos. Para saber de quem é o rosto, precisamos do reconhecimento.

Como funciona o reconhecimento (LBPH)

O LBPH (Local Binary Patterns Histograms) analisa as texturas locais da face e compara com faces previamente cadastradas. O fluxo tem 3 etapas:

  1. Coletar amostras do rosto pela webcam
  2. Treinar um modelo LBPH com as amostras e seus labels
  3. Reconhecer rostos ao vivo comparando com o modelo treinado

Na prática, o predict retorna o label (ID da pessoa) e a confiança — quanto menor a confiança, maior a certeza do reconhecimento.

Passo 4 — Detectar rostos com Haar Cascades

Crie o arquivo detectar_rostos.py:


type nul > detectar_rostos.py

Abra o arquivo e insira o código:


import cv2
import sys

# Carrega o classificador
face_cascade = cv2.CascadeClassifier("haarcascade_frontalface_default.xml")

# Carrega a imagem
img = cv2.imread("grupo.jpg")
if img is None:
    print("Erro: imagem 'grupo.jpg' nao encontrada. Coloque-a ao lado dos scripts.")
    sys.exit(1)
cinza = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

# Detecta rostos
rostos = face_cascade.detectMultiScale(
    cinza,
    scaleFactor=1.1,
    minNeighbors=5,
    minSize=(30, 30)
)

# Desenha retângulos ao redor dos rostos
for (x, y, w, h) in rostos:
    cv2.rectangle(img, (x, y), (x + w, y + h), (0, 255, 0), 2)

print(f"Rostos detectados: {len(rostos)}")

cv2.imshow("Deteccao Facial", img)
cv2.waitKey(0)
cv2.destroyAllWindows()

Use uma foto de grupo (grupo.jpg) e execute:


python detectar_rostos.py

Parâmetros do detectMultiScale

Parâmetro Descrição
scaleFactor Redução da escala a cada passo (1.1 = 10%)
minNeighbors Mínimo de vizinhos para validar detecção
minSize Tamanho mínimo do rosto a detectar

🤓 Explicando o código

cv2.CascadeClassifier(...)

Carrega o classificador pré-treinado de faces frontais a partir do arquivo haarcascade_frontalface_default.xml baixado no passo anterior — o OpenCV 5.0 não inclui mais esse arquivo no pacote pip. A partir dele chamamos o detectMultiScale.

detectMultiScale

Retorna uma lista de retângulos (x, y, w, h) — posição e tamanho de cada rosto encontrado. scaleFactor controla a redução de escala entre janelas e minNeighbors exige um mínimo de vizinhos para reduzir falsos positivos.

cv2.rectangle(...)

Desenha um retângulo verde (0, 255, 0) ao redor de cada rosto detectado.

Passo 5 — Detecção em tempo real com a webcam

Crie o arquivo webcam.py:


type nul > webcam.py

Abra o arquivo e insira o código:


import cv2
import sys

face_cascade = cv2.CascadeClassifier("haarcascade_frontalface_default.xml")

webcam = cv2.VideoCapture(0)
if not webcam.isOpened():
    print("Erro: nao foi possivel abrir a webcam.")
    sys.exit(1)

while True:
    ret, frame = webcam.read()
    if not ret:
        break

    cinza = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    rostos = face_cascade.detectMultiScale(cinza, 1.1, 5)

    for (x, y, w, h) in rostos:
        cv2.rectangle(frame, (x, y), (x + w, y + h), (0, 255, 0), 2)

    cv2.imshow("Webcam - Pressione Q para sair", frame)

    if cv2.waitKey(1) & 0xFF == ord("q"):
        break

webcam.release()
cv2.destroyAllWindows()

Execute e aponte a câmera para o seu rosto:


python webcam.py
  • VideoCapture(0) — abre a webcam padrão
  • read() — captura um frame (retorna bool + array)
  • Pressione Q para encerrar

🤓 Explicando o código

cv2.VideoCapture(0)

Abre a câmera do computador. O 0 é o índice da webcam padrão; se tiver outra câmera, use 1, 2, etc.

ret, frame = webcam.read()

Captura um frame. ret indica se a leitura funcionou e frame é a imagem capturada.

O loop while True

Processa frame a frame. A cada volta detectamos rostos, desenhamos os retângulos e exibimos o resultado. O waitKey(1) dá tempo de o frame ser exibido e, ao mesmo tempo, detecta se a tecla Q foi pressionada.

webcam.isOpened()

Verifica se a câmera realmente foi aberta. Se ela estiver em uso por outro programa ou desligada, o programa mostra uma mensagem clara em vez de travar.

Passo 6 — Coletar amostras do rosto

Para o reconhecimento, precisamos de imagens do rosto de cada pessoa. Crie o arquivo coletar_faces.py: 


type nul > coletar_faces.py

Abra o arquivo e insira o código:


import cv2
import os

face_cascade = cv2.CascadeClassifier(
    cv2.data.haarcascades + "haarcascade_frontalface_default.xml"
)

nome = input("Digite seu nome: ")
os.makedirs(f"faces/{nome}", exist_ok=True)

webcam = cv2.VideoCapture(0)
contador = 0

while contador < 30:
    ret, frame = webcam.read()
    if not ret:
        break

    cinza = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    rostos = face_cascade.detectMultiScale(cinza, 1.3, 5)

    for (x, y, w, h) in rostos:
        contador += 1
        face = cinza[y:y+h, x:x+w]
        face = cv2.resize(face, (200, 200))
        cv2.imwrite(f"faces/{nome}/{contador}.jpg", face)
        cv2.rectangle(frame, (x, y), (x+w, y+h), (0, 255, 0), 2)
        cv2.putText(frame, f"Amostra {contador}/30",
                    (x, y-10), cv2.FONT_HERSHEY_SIMPLEX, 0.7, (0, 255, 0), 2)

    cv2.imshow("Coletando Faces", frame)
    cv2.waitKey(100)

webcam.release()
cv2.destroyAllWindows()
print("Coleta finalizada!")

Passo 7 — Treinar o reconhecedor

Crie o arquivo treinar.py:


type nul > treinar.py

Abra o arquivo e insira o código:


import cv2
import os
import numpy as np

recognizer = cv2.face.LBPHFaceRecognizer.create()

faces = []
labels = []
label_map = {}
label_id = 0

for pasta in os.listdir("faces"):
    caminho = os.path.join("faces", pasta)
    if not os.path.isdir(caminho):
        continue
    label_map[label_id] = pasta
    for arquivo in os.listdir(caminho):
        img = cv2.imread(os.path.join(caminho, arquivo), 0)
        img = cv2.resize(img, (200, 200))
        faces.append(img)
        labels.append(label_id)
    label_id += 1

recognizer.train(faces, np.array(labels))
recognizer.save("treino.yml")

print("Treino concluido!")
print("Mapa de labels:", label_map)

Execute para treinar o modelo:


python treinar.py

🤓 Explicando o código

LBPHFaceRecognizer.create()

Cria o reconhecedor baseado em LBPH. Ele vem no opencv-contrib-python, por isso instalamos esse pacote.

label_map

Associa cada número (label) a um nome de pessoa. O reconhecedor só trabalha com números, então o mapa serve para traduzir o resultado.

recognizer.train(faces, np.array(labels))

Treina o modelo com todas as amostras coletadas e seus labels. O resultado é salvo em treino.yml com recognizer.save().

import cv2

face_cascade = cv2.CascadeClassifier(
    cv2.data.haarcascades + "haarcascade_frontalface_default.xml"
)

recognizer = cv2.face.LBPHFaceRecognizer.create()
recognizer.read("treino.yml")

label_map = {0: "Joao", 1: "Maria"}  # Ajuste conforme sua coleta

webcam = cv2.VideoCapture(0)

while True:
    ret, frame = webcam.read()
    if not ret:
        break

    cinza = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    rostos = face_cascade.detectMultiScale(cinza, 1.3, 5)

    for (x, y, w, h) in rostos:
        face = cv2.resize(cinza[y:y+h, x:x+w], (200, 200))
        label, confianca = recognizer.predict(face)

        nome = label_map.get(label, "Desconhecido")
        cor = (0, 255, 0) if confianca < 70 else (0, 0, 255)
        texto = f"{nome} ({confianca:.0f}%)"

        cv2.rectangle(frame, (x, y), (x+w, y+h), cor, 2)
        cv2.putText(frame, texto, (x, y-10),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.7, cor, 2)

    cv2.imshow("Reconhecimento Facial - Pressione Q para sair", frame)

    if cv2.waitKey(1) & 0xFF == ord("q"):
        break

webcam.release()
cv2.destroyAllWindows()

recognizer.predict(face)

Passo 9 — Projeto completo integrado

Para finalizar, vamos unir tudo em um único script com menu. Crie o arquivo main.py: 


type nul > main.py

Abra o arquivo e insira o código:


import cv2
import os
import numpy as np

face_cascade = cv2.CascadeClassifier(
    cv2.data.haarcascades + "haarcascade_frontalface_default.xml"
)

ARQUIVO_TREINO = "treino.yml"
PASTA_FACES = "faces"

def coletar():
    nome = input("Digite o nome da pessoa: ")
    destino = os.path.join(PASTA_FACES, nome)
    os.makedirs(destino, exist_ok=True)

    webcam = cv2.VideoCapture(0)
    contador = 0

    while contador < 30:
        ret, frame = webcam.read()
        if not ret:
            break
        cinza = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
        rostos = face_cascade.detectMultiScale(cinza, 1.3, 5)
        for (x, y, w, h) in rostos:
            contador += 1
            face = cv2.resize(cinza[y:y+h, x:x+w], (200, 200))
            cv2.imwrite(f"{destino}/{contador}.jpg", face)
            cv2.rectangle(frame, (x, y), (x+w, y+h), (0, 255, 0), 2)
            cv2.putText(frame, f"{contador}/30", (x, y-10),
                        cv2.FONT_HERSHEY_SIMPLEX, 0.7, (0, 255, 0), 2)
        cv2.imshow("Coletando - Q para cancelar", frame)
        if cv2.waitKey(100) & 0xFF == ord("q"):
            break

    webcam.release()
    cv2.destroyAllWindows()
    print(f"Coleta de '{nome}' finalizada com {contador} amostras.")

def treinar():
    recognizer = cv2.face.LBPHFaceRecognizer.create()
    faces, labels, label_map = [], [], {}

    for idx, pasta in enumerate(os.listdir(PASTA_FACES)):
        caminho = os.path.join(PASTA_FACES, pasta)
        if not os.path.isdir(caminho):
            continue
        label_map[idx] = pasta
        for arquivo in os.listdir(caminho):
            img = cv2.imread(os.path.join(caminho, arquivo), 0)
            if img is None:
                continue
            faces.append(cv2.resize(img, (200, 200)))
            labels.append(idx)

    if not faces:
        print("Nenhuma face encontrada para treino.")
        return {}

    recognizer.train(faces, np.array(labels))
    recognizer.save(ARQUIVO_TREINO)
    print(f"Treino concluido com {len(faces)} amostras.")
    return label_map

def reconhecer(label_map):
    if not os.path.exists(ARQUIVO_TREINO):
        print("Arquivo de treino nao encontrado. Treine primeiro.")
        return

    recognizer = cv2.face.LBPHFaceRecognizer.create()
    recognizer.read(ARQUIVO_TREINO)

    webcam = cv2.VideoCapture(0)
    while True:
        ret, frame = webcam.read()
        if not ret:
            break
        cinza = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
        rostos = face_cascade.detectMultiScale(cinza, 1.3, 5)
        for (x, y, w, h) in rostos:
            face = cv2.resize(cinza[y:y+h, x:x+w], (200, 200))
            label, confianca = recognizer.predict(face)
            nome = label_map.get(label, "Desconhecido")
            cor = (0, 255, 0) if confianca < 70 else (0, 0, 255)
            cv2.rectangle(frame, (x, y), (x+w, y+h), cor, 2)
            cv2.putText(frame, f"{nome} ({confianca:.0f}%)",
                        (x, y-10), cv2.FONT_HERSHEY_SIMPLEX, 0.7, cor, 2)
        cv2.imshow("Reconhecimento - Q para sair", frame)
        if cv2.waitKey(1) & 0xFF == ord("q"):
            break

    webcam.release()
    cv2.destroyAllWindows()

if __name__ == "__main__":
    print("=== RECONHECIMENTO FACIAL ===")
    print("1 - Coletar amostras")
    print("2 - Treinar modelo")
    print("3 - Reconhecer ao vivo")
    opcao = input("Escolha uma opcao: ")

    if opcao == "1":
        coletar()
    elif opcao == "2":
        treinar()
    elif opcao == "3":
        mapa = treinar() if not os.path.exists(ARQUIVO_TREINO) else {}
        if not mapa:
            mapa = {}
            for idx, pasta in enumerate(os.listdir(PASTA_FACES)):
                if os.path.isdir(os.path.join(PASTA_FACES, pasta)):
                    mapa[idx] = pasta
        reconhecer(mapa)
    else:
        print("Opcao invalida.")
