🧩 PASSO 1 — ENTENDER O ATOMIC DESIGN

Atomic Design é uma metodologia criada por Brad Frost que organiza a interface em cinco níveis de complexidade, inspirados na química. Assim como a matéria é formada por átomos que se combinam em moléculas, nossas telas são formadas por pequenos componentes que se combinam em blocos maiores.

Os cinco níveis são:

  1. Átomos (Atoms) — os menores elementos da interface: botões, inputs, labels, títulos. Não podem ser divididos e não fazem sentido sozinhos.
  2. Moléculas (Molecules) — a união de dois ou mais átomos. Exemplo: um label + um input = um campo de formulário.
  3. Organismos (Organisms) — a união de várias moléculas formando uma seção completa. Exemplo: um formulário de login inteiro, ou a lista de produtos.
  4. Templates — o esqueleto da página: definem onde os organismos ficam posicionados, sem conteúdo real (layout).
  5. Páginas (Pages) — o template com o conteúdo real, ou seja, a tela que o usuário vê.

🎯 Por que usar Atomic Design?

  • Reutilização: o mesmo botão e o mesmo input são usados em várias telas.
  • Manutenção: para mudar a cor de todos os botões, alteramos um único arquivo.
  • Organização: pastas claras tornam o projeto previsível e fácil de navegar.
  • Escala: padrão muito usado em projetos profissionais de larga escala.

const Input = ({ id, type, name, value, onChange, placeholder }) => {
  const style = {
    width: '100%',
    padding: '8px',
    marginTop: '4px',
    border: '1px solid #ccc',
    borderRadius: '4px',
    boxSizing: 'border-box',
  };

  return (
    <input
      id={id}
      type={type || 'text'}
      name={name}
      value={value}
      onChange={onChange}
      placeholder={placeholder}
      style={style}
    />
  );
};

export default Input;

Button.jsx

const Button = ({ type, onClick, variant, children }) => {
  const cores = {
    primary: { backgroundColor: '#0073e6', color: '#fff' },
    success: { backgroundColor: '#16a34a', color: '#fff' },
    danger: { backgroundColor: '#dc2626', color: '#fff' },
  };

  const estilo = {
    padding: '10px 14px',
    border: 'none',
    borderRadius: '4px',
    cursor: 'pointer',
    marginRight: '6px',
    ...cores[variant || 'primary'],
  };

  return (
    <button type={type || 'button'} onClick={onClick} style={estilo}>
      {children}
    </button>
  );
};

export default Button;

🤓 Explicando o código 📝

Os átomos são componentes 100% reutilizáveis: eles recebem dados e funções por props e não conhecem nada do restante da aplicação. O Button aceita uma prop variant que troca as cores (primary, success, danger), permitindo usar o mesmo botão com estilos diferentes. No Input, definimos um estilo padrão que é aplicado a todos os campos.

🧪 PASSO 3 — CRIAR AS MOLÉCULAS

Moléculas combinam dois ou mais átomos. Vamos criar duas: FormField (um Label + um Input) e ProductCard (o nome do produto + os botões de ação).

FormField.jsx

import Label from '../atoms/Label';
import Input from '../atoms/Input';

const FormField = ({ id, label, ...inputProps }) => (
  <div style={{ marginBottom: '12px' }}>
    <Label htmlFor={id}>{label}</Label>
    <Input id={id} {...inputProps} />
  </div>
);

export default FormField;

ProductCard.jsx

import Button from '../atoms/Button';

const ProductCard = ({ produto, onEditar, onDeletar }) => (
  <li
    style={{
      display: 'flex',
      justifyContent: 'space-between',
      alignItems: 'center',
      padding: '10px',
      marginBottom: '8px',
      border: '1px solid #ddd',
      borderRadius: '6px',
    }}
  >
    <span>{produto.nome}</span>
    <div>
      <Button onClick={() => onEditar(produto._id)}>editar</Button>
      <Button variant="danger" onClick={() => onDeletar(produto._id)}>
        deletar
      </Button>
    </div>
  </li>
);

export default ProductCard;

🤓 Explicando o código 📝

O FormField usa o spread operator ( ...inputProps) para repassar todas as props do input ( type, name, value, onChange etc.) sem precisar listá-las uma a uma. O ProductCard recebe o produto e as funções onEditar e onDeletar — ele não sabe como essas funções funcionam, apenas as chama quando o usuário clica.

🧬 PASSO 4 — CRIAR OS ORGANISMOS

Organismos são seções completas formadas por várias moléculas. Vamos criar os formulários (LoginForm, RegistrarForm e ProductForm) e a lista de produtos (ProductList). Toda a lógica de requisições com Axios (incluindo o token no header) fica aqui.

LoginForm.jsx

import { useState } from 'react';
import axios from 'axios';
import { useNavigate } from 'react-router-dom';
import FormField from '../molecules/FormField';
import Button from '../atoms/Button';

const LoginForm = () => {
  const [formData, setFormData] = useState({ email: '', senha: '' });
  const navigate = useNavigate();

  const handleChange = (e) => {
    const { name, value } = e.target;
    setFormData({ ...formData, [name]: value });
  };

  const handleSubmit = async (e) => {
    e.preventDefault();
    try {
      const response = await axios.post(
        'https://projeto-node-step-t5i1.vercel.app/login',
        formData
      );
      localStorage.setItem('token', response.data.token);
      alert('Login realizado com sucesso!');
      navigate('/');
    } catch (error) {
      console.error('Erro ao fazer login:', error);
      alert('Erro ao fazer login');
    }
  };

  return (
    <form onSubmit={handleSubmit}>
      <FormField
        id="email"
        label="Email:"
        type="email"
        name="email"
        value={formData.email}
        onChange={handleChange}
        placeholder="Digite seu email"
      />
      <FormField
        id="senha"
        label="Senha:"
        type="password"
        name="senha"
        value={formData.senha}
        onChange={handleChange}
        placeholder="Digite sua senha"
      />
      <Button type="submit" variant="primary">Entrar</Button>
    </form>
  );
};

export default LoginForm;

ProductForm.jsx

import { useState } from 'react';
import FormField from '../molecules/FormField';
import Label from '../atoms/Label';
import Button from '../atoms/Button';

const ProductForm = ({ inicial, onSubmit, textoBotao }) => {
  const [formData, setFormData] = useState(
    inicial || {
      nome: '',
      preco: '',
      descricao: '',
      categoria: '',
      imagem: '',
      avaliacao: { nota: '', quantidade: '' },
    }
  );

  const handleChange = (e) => {
    const { name, value } = e.target;
    setFormData({ ...formData, [name]: value });
  };

  const handleAvaliacaoChange = (e) => {
    const { name, value } = e.target;
    setFormData({
      ...formData,
      avaliacao: { ...formData.avaliacao, [name]: value },
    });
  };

  const handleSubmit = (e) => {
    e.preventDefault();
    onSubmit(formData);
  };

  return (
    <form onSubmit={handleSubmit}>
      <FormField
        id="nome"
        label="Nome:"
        type="text"
        name="nome"
        value={formData.nome}
        onChange={handleChange}
        placeholder="Nome do produto"
      />
      <FormField
        id="preco"
        label="Preço:"
        type="number"
        step="0.01"
        name="preco"
        value={formData.preco}
        onChange={handleChange}
        placeholder="0.00"
      />
      <div style={{ marginBottom: '12px' }}>
        <Label htmlFor="descricao">Descrição:</Label>
        <textarea
          id="descricao"
          name="descricao"
          value={formData.descricao}
          onChange={handleChange}
          placeholder="Descrição do produto"
          style={{
            width: '100%',
            padding: '8px',
            marginTop: '4px',
            border: '1px solid #ccc',
            borderRadius: '4px',
            boxSizing: 'border-box',
          }}
        />
      </div>
      <FormField
        id="categoria"
        label="Categoria:"
        type="text"
        name="categoria"
        value={formData.categoria}
        onChange={handleChange}
        placeholder="Ex: masculino, feminino, eletronicos"
      />
      <FormField
        id="imagem"
        label="Imagem (URL):"
        type="text"
        name="imagem"
        value={formData.imagem}
        onChange={handleChange}
        placeholder="https://..."
      />
      <FormField
        id="nota"
        label="Nota da avaliação:"
        type="number"
        step="0.1"
        name="nota"
        value={formData.avaliacao.nota}
        onChange={handleAvaliacaoChange}
        placeholder="0.0"
      />
      <FormField
        id="quantidade"
        label="Quantidade de avaliações:"
        type="number"
        name="quantidade"
        value={formData.avaliacao.quantidade}
        onChange={handleAvaliacaoChange}
        placeholder="0"
      />
      <Button type="submit" variant="success">{textoBotao || 'Salvar'}</Button>
    </form>
  );
};

export default ProductForm;

pages/Home.jsx

import { useState, useEffect } from 'react';
import axios from 'axios';
import { useNavigate } from 'react-router-dom';
import PageLayout from '../components/templates/PageLayout';
import ProductList from '../components/organisms/ProductList';

const Home = () => {
  const [produtos, setProdutos] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);
  const navigate = useNavigate();

  const carregarProdutos = () => {
    axios
      .get('https://projeto-node-step-t5i1.vercel.app/produtos')
      .then((response) => {
        setProdutos(response.data);
        setLoading(false);
      })
      .catch((err) => {
        setError(err.message);
        setLoading(false);
      });
  };

  useEffect(() => {
    carregarProdutos();
  }, []);

  const deletarProduto = async (id) => {
    try {
      const token = localStorage.getItem('token');
      await axios.delete(
        `https://projeto-node-step-t5i1.vercel.app/produtos/${id}`,
        {
          headers: { Authorization: `Bearer ${token}` },
        }
      );
      carregarProdutos();
    } catch (err) {
      console.error('Erro ao deletar:', err);
      alert('Erro ao deletar produto');
    }
  };

  if (loading) return <p>Carregando produtos...</p>;
  if (error) return <p>Erro: {error}</p>;

  return (
    <PageLayout title="Home">
      <h2>Produtos</h2>
      <ProductList
        produtos={produtos}
        onEditar={(id) => navigate(`/produto/${id}`)}
        onDeletar={deletarProduto}
      />
    </PageLayout>
  );
};

export default Home;

pages/EditarProduto.jsx

import { useState, useEffect } from 'react';
import axios from 'axios';
import { useParams } from 'react-router-dom';
import PageLayout from '../components/templates/PageLayout';
import ProductForm from '../components/organisms/ProductForm';

const EditarProduto = () => {
  const { id } = useParams();
  const [produto, setProduto] = useState(null);

  useEffect(() => {
    axios
      .get(`https://projeto-node-step-t5i1.vercel.app/produtos/${id}`)
      .then((response) => setProduto(response.data))
      .catch((err) => console.error('Erro ao buscar produto:', err));
  }, [id]);

  const handleSubmit = async (formData) => {
    try {
      const token = localStorage.getItem('token');
      await axios.put(
        `https://projeto-node-step-t5i1.vercel.app/produtos/${id}`,
        formData,
        {
          headers: { Authorization: `Bearer ${token}` },
        }
      );
      alert('Produto atualizado com sucesso!');
    } catch (error) {
      console.error('Erro ao atualizar produto:', error);
      alert('Erro ao atualizar produto');
    }
  };

  if (!produto) return <p>Carregando produto...</p>;

  return (
    <PageLayout title="Editar Produto">
      <ProductForm
        inicial={produto}
        onSubmit={handleSubmit}
        textoBotao="Salvar"
      />
    </PageLayout>
  );
};

export default EditarProduto;

🚀 PASSO 8 — PUBLICAR NA VERCEL

A Vercel é uma plataforma gratuita que publica aplicações frontend de forma rápida e automática. Ela detecta projetos Vite sozinha, então o processo é bem simples.

1. Envie o código para o GitHub

Primeiro, faça o commit e o push da branch do projeto final:

git add .
git commit -m "projeto final: organiza codigo com atomic design"
git push --set-upstream origin projeto-final

2. Criar a conta e importar o projeto

  1. Acesse https://vercel.com e clique em Sign Up — use o botão "Continue with GitHub" para conectar sua conta.
  2. Após entrar, clique em Add New → Project.
  3. A Vercel vai listar seus repositórios do GitHub. Selecione o repositório projeto-react-step.
  4. Clique em Import.

3. Configurar e fazer o deploy

  1. Na tela de configuração, a Vercel detecta automaticamente o framework Vite.
  2. Confira os campos preenchidos automaticamente:
    • Framework Preset: Vite
    • Build Command: npm run build
    • Output Directory: dist
  3. Não precisa configurar variáveis de ambiente: nossa API já está publicada em https://projeto-node-step-t5i1.vercel.app e a URL está fixa no código.
  4. Clique em Deploy e aguarde alguns segundos.
