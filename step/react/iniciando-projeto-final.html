🧩 PASSO 1 — ENTENDER O ATOMIC DESIGN

Atomic Design é uma metodologia criada por Brad Frost que organiza a interface em cinco níveis de complexidade, inspirados na química. Assim como a matéria é formada por átomos que se combinam em moléculas, nossas telas são formadas por pequenos componentes que se combinam em blocos maiores.

Os cinco níveis são:

  1. Átomos (Atoms) — os menores elementos da interface: botões, inputs, labels, títulos. Não podem ser divididos e não fazem sentido sozinhos.
  2. Moléculas (Molecules) — a união de dois ou mais átomos. Exemplo: um label + um input = um campo de formulário.
  3. Organismos (Organisms) — a união de várias moléculas formando uma seção completa. Exemplo: um formulário de login inteiro, ou a lista de produtos.
  4. Templates — o esqueleto da página: definem onde os organismos ficam posicionados, sem conteúdo real (layout).
  5. Páginas (Pages) — o template com o conteúdo real, ou seja, a tela que o usuário vê.

🎯 Por que usar Atomic Design?

  • Reutilização: o mesmo botão e o mesmo input são usados em várias telas.
  • Manutenção: para mudar a cor de todos os botões, alteramos um único arquivo.
  • Organização: pastas claras tornam o projeto previsível e fácil de navegar.
  • Escala: padrão muito usado em projetos profissionais de larga escala.

PASSO 2 — Criar um Header

Crie um componente chamado Header e nele coloque o logo, menu de navegação, botão tema escuro/claro e botão de logout.

Obs1: O Header será usado em todas as páginas do aplicativo.

Obs2: O botão de tema escuro/claro deve alternar o tema da página. Conforme vimos na Aula 12.

Obs3: O botão de logout deve redirecionar o usuário para a página de login e limpar o token do localStorage. Conforme vimos na Aula 11.

PASSO 3 — Fazer o filtro de produtos

Implemente um filtro de produtos que permita aos usuários buscar e filtrar produtos por nome na página Home, a que lista os produtos

Obs: O filtro deve ser implementado como um componente reutilizável. Além disso, você deve usar o AutoComplete do material ui.

Obs2:Além do AutoComplete, implemente o botão filtrar. Nesse botão você pode adicionar a lógica para aplicar o filtro selecionado. Dica: você pode usar o estado do componente para armazenar o valor selecionado no AutoComplete e, ao clicar no botão filtrar, aplicar a lógica de filtragem na lista de produtos.

🚀 PASSO 4 — PUBLICAR NA VERCEL

A Vercel é uma plataforma gratuita que publica aplicações frontend de forma rápida e automática. Ela detecta projetos Vite sozinha, então o processo é bem simples.

1. Envie o código para o GitHub

Primeiro, faça o commit e o push da branch do projeto final:

git add .
git commit -m "projeto final: organiza codigo com atomic design"
git push --set-upstream origin projeto-final

2. Criar a conta e importar o projeto

  1. Acesse https://vercel.com e clique em Sign Up — use o botão "Continue with GitHub" para conectar sua conta.
  2. Após entrar, clique em Add New → Project.
  3. A Vercel vai listar seus repositórios do GitHub. Selecione o repositório projeto-react-step.
  4. Clique em Import.

3. Configurar e fazer o deploy

  1. Na tela de configuração, a Vercel detecta automaticamente o framework Vite.
  2. Confira os campos preenchidos automaticamente:
    • Framework Preset: Vite
    • Build Command: npm run build
    • Output Directory: dist
  3. Não precisa configurar variáveis de ambiente: nossa API já está publicada em https://projeto-node-step-t5i1.vercel.app e a URL está fixa no código.
  4. Clique em Deploy e aguarde alguns segundos.

📌 O que aconteceu?

A Vercel rodou o npm run build, que gera a pasta dist com o site pronto, e publicou essa pasta em uma URL pública. Ao final, você verá uma tela de sucesso com o link, geralmente no formato https://projeto-react-step.vercel.app.

4. Testar o projeto no ar

  1. Clique no link gerado para abrir o site publicado.
  2. Teste o fluxo completo: registre-se, faça login, liste os produtos, crie, edite e delete um produto.
  3. Compartilhe a URL com os colegas — qualquer pessoa pode acessar pela internet!

⚠️ Dica: atualizações automáticas

Toda vez que você fizer um git push para a branch conectada à Vercel, o site é publicado automaticamente (deploy automático). Para publicar a branch projeto-final pelo painel, garanta que ela esteja selecionada em Settings → Git → Production Branch, ou abra a aba Deployments e publique a branch desejada manualmente.
