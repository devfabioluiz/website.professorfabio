Como estilizar com CSS em componentes do React

Existem várias maneiras de usar CSS em uma aplicação React. Aqui estão duas abordagens populares:

Usando um Arquivo CSS Externo

Crie um arquivo CSS separado e importe-o no componente.


.container {
  background-color: #f9f9f9;
  color: #333;
  padding: 20px;
  border-radius: 8px;
  text-align: center;
  font-family: Arial, sans-serif;
}

  

import React from "react";
import "./App.css";

function App() {
  return (
    <div className="container"div>
      <h1>Olá, React com CSS!</h1>
      <p>Este é um exemplo simples de uso de CSS em React.</p>
    <div>
  );
}

export default App;

🤓 Explicando o código 📝

Este código CSS define uma classe .container com estilos para centralizar e estilizar um contêiner: fundo claro, bordas arredondadas, padding e fonte Arial. No React, esse CSS é importado diretamente no componente com import "./App.css", e as classes são aplicadas via className (equivalente ao class do HTML, mas adaptado ao JSX).

Usando Inline Styles

Os estilos são definidos como objetos JavaScript e aplicados diretamente nos elementos usando a propriedade style. 


import React from "react";

function App() {
  const estiloContainer = {
    backgroundColor: "#f9f9f9",
    color: "#333",
    padding: "20px",
    borderRadius: "8px",
    textAlign: "center",
    fontFamily: "Arial, sans-serif",
  };

  return (
    <div style={estiloContainer}>
      <h1>Olá, React com Estilos Inline!</h1>
      <p>Este é um exemplo simples de estilos inline.</p>
    </div>
  );
}

export default App;

🤓 Explicando o código 📝

Este exemplo demonstra estilos inline no React. Os estilos são definidos como um objeto JavaScript (estiloContainer) com propriedades em camelCase (ex: backgroundColor em vez de background-color). O objeto é passado para a prop style do elemento JSX. Essa abordagem é prática para estilos dinâmicos, mas não substitui arquivos CSS para estilos mais complexos.

Styled Components

O Styled Components é uma biblioteca para estilização no React que utiliza o conceito de CSS-in-JS, permitindo que estilos sejam escritos diretamente dentro de componentes JavaScript. Com ele, você cria estilos encapsulados e reutilizáveis ao definir componentes estilizados usando a função styled, fornecida pela biblioteca. Por exemplo, você pode criar um botão estilizado com const Botao = styled.button`background-color: blue; color: white;`;. Esses componentes são utilizados como qualquer outro componente React, garantindo que os estilos sejam aplicados de forma específica sem afetar outros elementos da aplicação. Além disso, o Styled Components suporta dinamicidade, permitindo passar propriedades para alterar estilos de maneira flexível, como background-color: ${props => props.cor || 'blue'};. Essa abordagem combina o poder do JavaScript e do CSS, simplificando a manutenção e organização de estilos em aplicações React modernas.

Instale e veja como funciona em: Documentação do Styled Components

Exemplo
        
import styled from 'styled-components';

const Button = styled.button\`
    background: \${props => (props.primary ? 'blue' : 'gray')};
    color: white;
    padding: 10px;
    border: none;
    border-radius: 5px;
    cursor: pointer;
\`;

function App() {
    return (
        <div>
            <Button primary>Primary</Button>
            <Button>Secondary</Button>
        </div>
    );
}

🤓 Explicando o código 📝

O Styled Components usa a sintaxe de tagged template literals (crases) para criar componentes estilizados. styled.button cria um componente button com os estilos CSS definidos dentro das crases. As props são acessadas via ${props => ...}, permitindo estilos dinâmicos. O componente Button criado pode ser usado como qualquer outro componente React, aceitando props como primary para alterar sua aparência.

Veja este artigo que explica sobre o atual cenário do Styled Components: Styled Components: Um adeus ou um até logo?

Emotion

Emotion é uma biblioteca de estilização em JavaScript que permite criar estilos dinâmicos para componentes React e outros frameworks. Ela combina a flexibilidade do CSS-in-JS com uma API simples e poderosa, oferecendo suporte para estilos globais, temáticos e específicos de componentes. A geração de estilos ocorre em tempo de execução, permitindo que você altere dinamicamente as propriedades de estilo com base em variáveis ou estados do componente. Emotion também suporta a integração com TypeScript e oferece várias formas de uso, como o uso de classes estilizadas (`styled`) ou a aplicação direta de estilos com a função `css`. Essa abordagem facilita a criação de interfaces modernas e altamente personalizáveis.

Instale e veja como funciona em: Documentação do Emotion

Exemplo
        
/** @jsxImportSource @emotion/react */
import { css } from '@emotion/react';

const buttonStyle = primary => css\`
    background: \${primary ? 'blue' : 'gray'};
    color: white;
    padding: 10px;
    border: none;
    border-radius: 5px;
    cursor: pointer;
\`;

function Button({ primary, children }) {
    return <button css={buttonStyle(primary)}>{children}</button>;
}

🤓 Explicando o código 📝

O Emotion com a função css cria estilos dinâmicos em tempo de execução. A função buttonStyle recebe um parâmetro e retorna um estilo CSS condicional. O componente Button usa a prop css (disponível graças ao pragma @emotion/react) para aplicar o estilo. Essa abordagem permite lógica JavaScript dentro dos estilos, como o operador ternário que escolhe a cor de fundo.

Vanilla Extract

Vanilla Extract é uma biblioteca de CSS-in-TypeScript que permite criar estilos com tipagem estática e gerar arquivos CSS em tempo de build. Diferentemente de outras soluções CSS-in-JS, ela elimina a necessidade de aplicar estilos em tempo de execução, melhorando a performance da aplicação. Com Vanilla Extract, os estilos são escopados automaticamente, semelhantes ao CSS Modules, e é possível criar

Instale e veja como funciona em: Documentação do Vanilla Extract

Exemplo
        
// Criar um arquivo chamado styles.css.ts e inserir o código abaixo
import { style } from '@vanilla-extract/css';

export const botao = style({
  backgroundColor: 'blue',
  color: 'white',
  padding: '10px 20px',
  borderRadius: '5px',
  border: 'none',
  cursor: 'pointer',
  ':hover': {
    backgroundColor: 'darkblue',
  },
});

🤓 Explicando o código 📝

O Vanilla Extract usa a função style() para definir estilos com tipagem estática em arquivos .css.ts. Diferente do CSS-in-JS tradicional, os estilos são compilados em arquivos CSS estáticos durante o build, eliminando a sobrecarga de tempo de execução. O objeto de estilo aceita pseudosseletores como :hover diretamente nas propriedades. 



import React from 'react';
import * as styles from './styles.css';

function Botao() {
  return <button className={styles.botao}>Clique Aqui</button>;
}

export default Botao;

🤓 Explicando o código 📝

No Vanilla Extract com React, o componente importa os estilos via import * as styles from './styles.css' e aplica as classes CSS com className={styles.botao}. Como os estilos são gerados em tempo de build, o styles.css é um arquivo CSS real, e não uma string injetada em tempo de execução — isso resulta em melhor performance.

git checkout aula6-estilizacao-componentes — Muda para a branch aula6-estilizacao-componentes que foi criada no GitHub. Como a branch já existe no repositório remoto, o git fetch a torna disponível localmente.

Passo 2 — Estilizar botão com CSS externo

Crie o arquivo Button.css:


.btn-custom {
  background-color: #6200ea;
  color: white;
  padding: 12px 24px;
  border: none;
  border-radius: 8px;
  font-size: 16px;
  cursor: pointer;
  transition: background-color 0.3s;
}

.btn-custom:hover {
  background-color: #3700b3;
}

🤓 Explicando o código 📝

Este arquivo Button.css define os estilos para o botão personalizado. A classe .btn-custom usa background-color: #6200ea (roxo) e bordas arredondadas. O transition: background-color 0.3s suaviza a mudança de cor ao passar o mouse. A pseudoclasse :hover escurece o fundo para #3700b3, dando feedback visual ao usuário.

Depois crie o componente ButtonCSS.jsx:


import './Button.css';

const ButtonCSS = ({ label }) => {
  return <button className="btn-custom">{label}</button>;
};

export default ButtonCSS;

🤓 Explicando o código 📝

O componente ButtonCSS é um componente funcional que recebe a prop label via desestruturação. Ele importa o arquivo CSS externo ./Button.css (o Vite aplica os estilos globalmente) e renderiza um botão com a classe btn-custom usando className. O texto do botão é dinâmico, vindo da prop label.

Passo 3 — Estilizar botão com Inline Styles

Agora crie o componente ButtonInline.jsx e coloque o código abaixo: 


const ButtonInline = ({ label, primary }) => {
  const styles = {
    backgroundColor: primary ? '#1976d2' : '#9e9e9e',
    color: 'white',
    padding: '12px 24px',
    border: 'none',
    borderRadius: '8px',
    fontSize: '16px',
    cursor: 'pointer',
    margin: '4px',
  };

  return <button style={styles}>{label}</button>;
};

export default ButtonInline;

🤓 Explicando o código 📝

O ButtonInline usa estilos inline com um objeto JavaScript. A prop primary determina a cor de fundo via operador ternário: azul (#1976d2) se primary for verdadeiro, cinza (#9e9e9e) caso contrário. O objeto styles usa camelCase para as propriedades CSS (ex: backgroundColor em vez de background-color).

Passo 4 — Estilizar botão com Styled Components

Instale a biblioteca:


npm install styled-components

🤓 Explicando o código 📝

O comando npm install styled-components baixa e instala a biblioteca Styled Components no projeto, adicionando-a às dependências do package.json. Após a instalação, podemos importar a função styled para criar componentes estilizados.

Depois crie um componente chamado ButtonStyled.jsx e coloque o código abaixo nele: 


import styled from 'styled-components';

const StyledBtn = styled.button`
  background: ${(props) => (props.primary ? '#6200ea' : '#9e9e9e')};
  color: white;
  padding: 12px 24px;
  border: none;
  border-radius: 8px;
  font-size: 16px;
  cursor: pointer;
  margin: 4px;
  transition: background 0.3s;

  &:hover {
    background: ${(props) => (props.primary ? '#3700b3' : '#757575')};
  }
`;

const ButtonStyled = ({ label, primary }) => {
  return <StyledBtn primary={primary}>{label}</StyledBtn>;
};

export default ButtonStyled;

🤓 Explicando o código 📝

O Styled Components StyledBtn é criado com styled.button e template literals. As props são acessadas com ${(props) => ...} para estilos condicionais. O componente ButtonStyled renderiza StyledBtn passando a prop primary, que define as cores. O &:hover usa o operador & do Sass para referenciar o próprio elemento no hover.

Passo 5 — Usar todos os botões no App


import ButtonCSS from './ButtonCSS';
import ButtonInline from './ButtonInline';
import ButtonStyled from './ButtonStyled';

function App() {
  return (
    <div>
      <h1>Botão com CSS Externo</h1>
      <ButtonCSS label="CSS Externo" />

      <h1>Botão com Inline Styles</h1>
      <ButtonInline label="Primário" primary />
      <ButtonInline label="Secundário" />

      <h1>Botão com Styled Components</h1>
      <ButtonStyled label="Primário" primary />
      <ButtonStyled label="Secundário" />
    </div>
  );
}

export default App;

🤓 Explicando o código 📝

O App.jsx importa os três componentes de botão criados nos passos anteriores: ButtonCSS, ButtonInline e ButtonStyled. Cada um é renderizado com diferentes props para demonstrar as três abordagens de estilização. O ButtonInline e ButtonStyled usam a prop primary para alternar entre estilo primário e secundário.
